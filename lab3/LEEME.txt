PREPARACIÓN (una sola vez)
  1. Descomprime este paquete en una ruta SIN espacios con tu nombre y apellido (por ejemplo C:\juan_perez).
  2. Copia los CSV indicados dentro de datos_originales/
     (o usa:  python preparar_datos.py --entrada "RUTA\MachineLearningCVE" ).
  3. Instala las librerías:
         pip install -r requerimientos.txt
  4. Abre una terminal en esta carpeta y ejecuta la limpieza:
         python preparar_datos.py
     Debe terminar con "Listo" y crear web_limpio.csv.gz y bot_limpio.csv.gz en datos_limpios/.
     Cifras de control: web = 164.179 filas y 2.143 ataques; bot = 184.044 filas y 1.948 ataques.

TRABAJO
  5. Ejecuta la plantilla sin tocar nada (verás mensajes [PENDIENTE]):
         python practica3_plantilla.py --dataset web
  6. Completa, en orden, los 6 TODO de practica3_plantilla.py:
         metricas · evaluar_regla_puerto · entrenar_arbol · reglas_texto · barrido_umbral · elegir_umbral
     Después de cada TODO vuelve a ejecutar y revisa los resultados y la carpeta figuras/.
  7. Extensión (botnet):            python practica3_plantilla.py --dataset bot
  8. Opcional A (prevalencia):      python practica3_plantilla.py --dataset web --prevalencia
  9. Opcional B (contraste DDoS):   python practica3_plantilla.py --dataset ddos

ENTREGABLE (UN SOLO ZIP: apellido_nombre_practica3.zip)
  Contenido del zip: tu carpeta practica3/ con
      practica3_plantilla.py    terminado (los 6 TODO resueltos)
      p3_utils.py               sin modificar

                                y al menos cinco gráficos comentados
      figuras/                  PNG y CSV generados por tu script, de web y de bot
  Antes de comprimir: ejecuta la plantilla para web y para bot, y VACÍA datos_originales/ y datos_limpios/
  (son muy grandes y no se entregan).
  IMPORTANTE: no cambies los nombres de archivos ni de funciones.
  Detalle completo en la guía (sección 9).
